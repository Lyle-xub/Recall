# Recall 0.4.7 时间线与搜索栏细化

日期：2026-09-25。仅 macOS，最终构建 13。

## 改动

- 应用分组弹窗移除内容内部的第二层 Liquid Glass 圆角，仅由原生 popover 管理外缘。列表保留 8 点内边距、44 点点击高度，以及应用图标和时间区间。
- 开始录制不再调用 hideOverlay。设置页发起录制时只关闭设置页并返回时间线；直接从时间线菜单发起时浮层保持打开。
- Recall 处于前台时，从所录显示器的可见普通窗口中确定下方应用，保存对应应用名、标识和标题。自己的所有窗口继续由 ScreenCaptureKit 排除。下方窗口属于排除应用时仍跳过记录，不会跳到下一应用来规避排除逻辑。
- 时间线取色改为真实应用图标的 48×48 像素采样：忽略透明区，按色相聚合主色，避免白色底板和黑色轮廓稀释彩色标记；黑白图标保留中性色。结果按应用缓存；图标不可取得时使用中性色。
- 搜索栏和四个按钮使用共享 GlassEffectContainer、稳定 glassEffectID 和 matchedGeometry 过渡。按钮由搜索框右缘向各自位置展开，接近时融合，最终保留独立间距；兼容减少动态效果设置，旧版 macOS 使用材质回退。[Apple Liquid Glass 容器](https://developer.apple.com/documentation/swiftui/glasseffectcontainer)、[形状过渡](https://developer.apple.com/documentation/swiftui/glasseffecttransition/matchedgeometry)。
- 关闭、返回、菜单、右侧搜索动作、时间线缩放及回看工具栏使用统一图标色。选中状态由填充符号或小圆点区分。
