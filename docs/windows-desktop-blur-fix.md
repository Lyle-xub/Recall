# Windows 桌面背景模糊修复

本修正版解决上一份便携版“背景接近白灰色、几乎不透出桌面”的问题。请使用 `Recall-Windows-x64-background-fix.zip`，不要继续使用旧的 `visual-dev` 压缩包。

## 原因与修改

旧版全页浅色背景采用 10% 桌面颜色与 90% 固定灰白色混合。虽然模糊图层已连接，桌面颜色和轮廓被固定色压得很淡，看起来像一整块灰白背景。上一轮将 Mac 的 **withinWindow** 材质参考用于拟合 Windows 的 **host desktop** 透明度，验收方式不足以证明真实桌面的效果。

新版全页桌面采样权重为 60%，浅色／深色分别使用白色／深色混合层，模糊半径 22。经典首页仍保留局部搜索框和底部渐变遮罩。没有取消窗口捕获排除，也没有使用壁纸图或截图循环冒充实时模糊。

## 验证

- 以**普通启动方式**运行，使用独立空资料库、关闭录制；不是 `--visual-parity` 启动。用户已确认：“能看出桌面内容，且已模糊”。
- 普通启动诊断：Windows 桌面模糊接口返回 0（成功），捕获排除值仍为 17，advancedEffects=true、effectsAvailable=true、usingFallback=false；桌面权重 0.6、模糊半径 22。
- 受控桌面由大色块和 2 像素细线组成。蓝红区域平均 RGB 差异从 **8.94** 提升到 **54.15**，超过旧版 6 倍；模糊后区域细线变化标准差 **0.80/255**。
- 仅改变独立背景窗口，不刷新 Recall 材质：采样区域平均 RGB 变化 **54.15/255**，证实背景持续更新。
- 7 个真实背景测试场景覆盖新旧配比、浅深色、动态更新、Rhine、搜索与经典首页。
- 12 项原生材质／降级／失败恢复检查通过；17 个页面状态重新捕获，未发现材质连接错误或 Rhine 图片加载失败。
- 89 项回归检查通过；Release x64 自包含发布成功。

此前报告中背景参考图的 SSIM 属于**旧配比**，不适用于本修正版，不能继续用于宣称实际桌面或整体界面达到 90%。

原始截图与普通启动诊断随开发交付文件 background-fix-evidence/ 提供。

## 复现与源码

仓库新增 `scripts/test-windows-desktop-blur.ps1` 和 `scripts/verify-windows-desktop-blur.py`（Pillow、NumPy）。前者按 JSON 场景生成捕获，后者检查桌面颜色保留、细线模糊和不重建材质时的动态采样。普通启动时会在资料库目录写入 `material-diagnostics.json`，仅包含技术状态，不包含查询、历史内容或截图。

完整源码补丁 `windows-glass-background-fix.patch` 基于仓库 `12c9aac`，包含之前的实现和本次修正；如果已应用旧补丁，请使用当前工作区修改，而不是重复套用完整补丁。源码仍在本地工作区，未推送 GitHub。

原生窗口保留捕获排除，因此自动截图不能直接显示普通运行窗口。普通路径由状态诊断和用户目视共同确认，PNG 来自独立合成验证模式；两者明确区分。

最终页面证据为 `desktop-app-complete-*`。早先冷启动中仅显示背景的三张图已拒收；验证脚本增加了预热，并修复指令文件读写冲突（原子替换和有限重试）。旧尝试保留供复查，不计入 17 个有效状态。
