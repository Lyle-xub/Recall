## 实际修正

- 时间跨度改为异步弹出浮层，去除这处原生菜单的同步事件循环。
- 转写列表使用 LazyVStack，按可见区域排版；文本高亮处理拒绝零长度匹配，防止循环不前进。
- 转写批量提交、收藏、恢复、移入废纸篓及设置保留期处理在后台写库，不在主线程争抢媒体归档的锁。转写完成不再全量 reload 时间线；时间戳跳转复用合并异步导航。
- Whisper 整个准备、转码、推理阶段共用异步串行租约。此前只在等待异步准备前检查进程，actor 重入时可能同时启动多个引擎。取消会释放队列；线程数上限从 8 改为 4，后台优先级运行。
- 音频转换支持取消，并在持续不读入也不输出时结束报错，防止转换器无进展循环。
- 加入本地 UI 队列响应诊断：延迟超过 6 秒时采集 2 秒线程栈，一分钟最多一次、同一延迟只一次、最多保留三份，仅保存到应用数据目录 diagnostics。没有自动退出、重启或上传。
