# Native dependencies

This is an independent implementation. It is not an official Rewind product.

- llama.cpp b11160 — ggml-org, MIT. See llama.cpp-MIT.txt.
- whisper.cpp v1.8.3 — ggml-org, MIT. See whisper.cpp-MIT.txt.
- Qwen3-1.7B GGUF model — Qwen, Apache-2.0. Downloaded separately from the pinned official repository; see Qwen3-Apache-2.0.txt.
- Whisper Base weights — OpenAI Whisper / ggerganov GGML conversion, MIT; downloaded separately.
- Tesseract 5.2 .NET wrapper / native Tesseract — Apache-2.0. https://github.com/charlesw/tesseract and https://github.com/tesseract-ocr/tesseract
- tessdata_fast English and Simplified Chinese v4.1.0 — Apache-2.0. https://github.com/tesseract-ocr/tessdata_fast
- ScreenRecorderLib 7.0.1 — MIT. https://github.com/sskodje/ScreenRecorderLib
- NAudio 2.2.1 — MIT. https://github.com/naudio/NAudio
- .NET runtime and Microsoft.Data.Sqlite — MIT. https://github.com/dotnet/runtime and https://github.com/dotnet/efcore
- SQLitePCLRaw — Apache-2.0. https://github.com/ericsink/SQLitePCL.raw
- SQLite — public domain. https://sqlite.org/copyright.html

Additional notices shipped with vendor binary archives, including LLVM/OpenMP notices, are retained alongside the libraries. Model licenses and engine notices are bundled with both applications. OS frameworks are supplied by the operating system.
