# Windows 原生迁移与 macOS 对齐

基准：已公证的 macOS Recall 0.4.25。Windows 使用 WinUI 3 / Windows App SDK、C# 服务、Win32 窗口互操作和 Composition；不使用网页壳。

## 实施与验收

1. 将设置、搜索、共享 OCR、去重持续区间、独立应用使用时间、录制状态协调、转写展示和清理逻辑放入可测试服务。
2. 建立 WinUI 桌面覆盖层：原桌面可见、底部渐变模糊、连续彩色时间线、固定游标、缩放、密集图标弹层和较小历史预览。
3. 搜索工具条以收缩与弹性展开衔接应用筛选、收藏、Ask、Usage、设置；搜索结果三列、图片文字跨行选择、视频圆角、可复制转写与按媒体显示状态。
4. 同步白色纵向设置、自定义快捷键、权限入口、真实存储图表、优化与清理、内置模型下载和在线模型配置。
5. 同步 Usage 日历、周/小时图表、应用排行、首次启动虹彩玻璃光环与无敲击音效；保留跳过、静音及减少动画支持。
6. 开启界面暂停屏幕和音频采集，关闭后仅恢复用户原有录制意愿；OCR/转写继续后台处理。截图在压缩前 OCR，完全相同像素复用图片和文字；视频最长边 720、1 fps、100 kbps，无重复内嵌音轨。
7. 验证核心行为和 C# 编译，Windows 真机验证透明度、任务栏鼠标拦截、DPI/多显示器、录屏和音频。未经真机验证的项目明确标记，不能把源码检查当作视觉验收。

## 视觉规范

- 同一份 Recall 图标、Halo、虹彩玻璃和开场音效。
- 搜索框 72 → 58 DIP；功能圆按钮 58 DIP；主要点击目标至少 44 DIP。
- 白色主表面、柔和灰色文字、同一组低饱和青/紫/珊瑚点缀，连续圆角。
- 时间线底部约 230 DIP，模糊在上缘平滑衰减；历史画面保留边距和 Recorded 时间说明。
- 原生 Windows 字体和键盘符号，其余间距、图标线宽、布局与动效节奏对齐 macOS。

当前 Windows WPF 工程保留为旧版源码参考；新发行入口为 `Windows/Recall.WinUI`。Mac 发布包和应用代码保持不变。
