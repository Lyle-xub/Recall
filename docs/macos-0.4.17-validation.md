# Recall 0.4.17：识别与采集暂停分离

2026-09-25，macOS build 24。Windows 未改动。

## 修改

- 打开 Recall 仍立即拒绝新截图并停止屏幕、系统声音及麦克风采集；关闭后根据用户此前的录制意愿恢复。手动暂停和退出逻辑保留。
- 移除屏幕索引及语音转写对界面可见性的等待条件。之前已保存的截图、已结束的录音片段在时间线、详情、搜索、设置等界面打开时继续识别、保存结果和更新搜索索引。
- OCR 和转写队列使用 utility 优先级；识别引擎、音频转换、数据库提交仍在后台。备用本地 OCR 子进程也使用 utility。保留每种引擎串行处理、Whisper 最多四线程及取消检查。
- 胶囊不再因界面打开显示 paused；显示 Recognizing text / Transcribing audio、queued、Up to date 或异常信息。等待状态说明无需关闭 Recall。大型存储优化仍沿用原有独立策略。

## 验证

- 21 项相关回归：20 通过、1 项可选真实库检查跳过，无失败。涵盖录制生命周期、快速开关、手动暂停、异步导航、转写队列与取消。
- 新增回归在整个测试中保持界面打开并请求录制：实际采集保持暂停，一张既有截图通过真实 OCR 完成索引；两个已有音频任务通过确定性的测试语音接口完成队列与数据库提交；历史截图数量保持为 1，没有产生新截图。语音接口测试不发送网络请求，不验证语音模型准确率。
- 实机、安装包与数据校验结果将在下方记录。
