# Recall 0.4.19：当前媒体的识别状态

2026-09-25，macOS build 26；包含 0.4.17–0.4.18 的识别暂停逻辑及防闪烁修正。

## 行为

- 打开 Recall 暂停屏幕、麦克风及系统声音采集；已有截图和已结束录音继续低优先级识别，不因打开界面显示 paused。大型存储压缩仍采用独立的暂停策略。
- 详情中的胶囊按当前图片 ID / 录音片段 ID 取状态，不展示后台总队列数量，也不会继承其他内容的异常。
- 图片显示当前图片的 OCR 状态；会议副图使用自己的文字结果。独立导入图片没有语音胶囊。带录音的图片同时显示所属录音片段的转写状态，播放视频时只显示该片段的音频状态，不宣称对视频进行 OCR。
- 区分排队、识别中、完成、无文字/无语音、无音轨、未处理、未启用和异常。旧记录有文字结果可确认为完成；无旧结果及完成记录时，不以队列为空推断成功。
- 新增独立的语音结果状态表，完成标记与转写原文在同一数据库事务提交；保存无语音结果及错误。清理录音时自动删除对应状态，不修改原始转写或录屏文件。
- 同一内容的短暂状态变化合并 180 毫秒，取消图标切换动画；内容切换立即更新状态，旧任务的延迟通知不能覆盖新选择。异常立即显示。识别中的状态涵盖结果写入。
- 媒体状态单独观察，完成状态缓存最多 128 个录音片段；异步读取当前片段资料，不在 SwiftUI body 中查询数据库。
