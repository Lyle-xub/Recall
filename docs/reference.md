# Rewind 视频参考记录

参考：[Rewind Demo，用户指定视频](https://www.youtube.com/watch?v=dIV0ZiZluQo&t=11s)，约 2 分 10 秒。已查看视频的搜索、会议详情和时间线画面，并读取字幕核对交互顺序。

| 视频位置 | 观察到的交互 | 原生实现 |
|---|---|---|
| 0:12–0:17 | 全局快捷键呼出、覆盖 Dock、居中浮动搜索 | Carbon 热键 / Windows RegisterHotKey；Mac 默认透明桌面悬浮，拖动后进入历史画面 |
| 0:20–0:40 | 底部时间轨道、回到过去、复制文字 | Mac 固定中心指针、时长比例轨道、日期跳转、原生 Live Text 范围选择 |
| 0:48–1:17 | 跨应用关键词搜索，三列卡片、应用筛选 | 本地文字 / 转写搜索、三列原生卡片和过滤按钮 |
| 1:20–1:37 | 打开会议，右侧对话，查找词语 | 历史画面详情、带时间戳转写、关键词高亮 |
| 1:38–1:46 | 左下角画中画切换桌面与会议 | 同一采样时刻的桌面 / 独立会议窗口图像 |
| 1:49–2:00 | 打开共享画面里出现的链接 | OCR 文字中检测 HTTP(S) 链接并打开系统浏览器 |

macOS 新界面依据用户随后提供的三张截图重构（Windows 本轮保持原样）：

- 图 1：桌面保持真实、清晰，中央搜索框使用系统 Liquid Glass。仅底部 220 pt 是逐渐淡出的桌面模糊层；窗口层级高于 Dock，不预留 Dock 区域。
- 图 2：拖动轨道后切换至该时刻的真实屏幕记录，保持中央白色指针不动，彩色应用片段按时间长度平移；顶部为相对时间胶囊，右侧箭头返回实时桌面。历史画面里的文字由 VisionKit Live Text 支持按词、按范围选择复制。
- 图 3：搜索框移动到顶部，背景改为真实桌面的全屏模糊，应用筛选胶囊、三列结果卡片统一使用原生玻璃和连续圆角，保留应用图标、标题、时间与关键词高亮。
- 搜索框位移、悬浮层出现和卡片悬停使用系统弹簧或淡入动画，并响应“减少动态效果”。macOS 26+ 使用 Liquid Glass，较旧的系统使用原生材质。
- Mac 的 Demo 入口、命令行 Demo 开关和合成记录生成器已移除；读取库时始终排除历史演示记录。


在线 / 本地模型、导入、导出、存储和录制选项放在菜单及独立设置面板。视频没有展示 AI 对话界面，这一部分是新增设计，不属于能够从视频逐像素验证的内容。

Windows 保留上一版合成演示内容。Mac 本轮不以这些演示图片代替实际录制测试。原版截图的字体、应用图标、窗口素材和底层压缩算法没有被当作已获得的源文件使用。
