# CLI 可读性优化计划

本轮以“人在终端里快速找到结果”为目标。协调代理负责规划、独立验收和
Mac 安装；GPT-6-Sol（xhigh）负责核心代码与回归测试。

## 现状与范围

当前 0.5.0 默认把所有返回对象打印成缩进 JSON。搜索和记录列表会混入
完整 OCR、坐标数组、内部路径，帮助信息也缺少清晰的阅读顺序。

改动集中于 CLI 的参数、帮助与呈现层，不改变资料库格式、搜索匹配规则、
录制逻辑或模型选择。机器使用的 `--json` 保留原始字段、信封格式、错误码
及默认查询数量。兼容的桌面应用无需重新安装。

## 呈现规范

1. 搜索、记录列表：人类模式默认 10 条；每条突出时间、应用、标题、完整
   ID 和短摘要。摘要尽量围绕命中位置，不展示坐标或整段 OCR。正文未包含
   查询词时，不编造命中位置。显示本页数量、可复制的下一页命令及详情查看用法，
   不把“本页数量”写成“全部匹配数量”。显式 `--limit` 仍然生效。
2. 记录详情：提供清楚的元数据与正文，保留读取完整内容的能力。
3. 状态输出：资料库、诊断、录制、任务、模型和存储使用摘要、键值或短表。
   集合输出有界；如省略内容，提示如何获取完整数据。暂停、离线、失败、
   空结果均使用明确文字，不只靠颜色表达。
4. 操作结果：导入、导出、收藏、恢复、配置和存储操作突出实际结果与下一步。
   失败给出具体原因和修正示例。保持原有退出码和确认语义。
5. 帮助：按用途分组，以常用示例开头；支持 `recall help`、主题帮助和
   `recall search --help`。命令名保持英文，标签和帮助根据终端语言选择
   中文或英文，可用 `--lang zh|en` 指定。OCR 的 `--language` 含义不变。

## 终端适配

- 用颜色区分标题、成功、警告、错误和次要信息，少量图标放在标题或状态旁。
- 支持 `--color auto|always|never` 和 `--ascii`；遵守自动模式下的
  `NO_COLOR`、`TERM=dumb` 及重定向，标准输出和错误输出分别判断。
- `--json` 永不包含 ANSI 或装饰文本；原有 JSON 进度协议保留。
- 正确处理中文宽度、组合字符和 emoji；窄窗口中不切断 Unicode 字符。
  记录 ID 和复制命令不能因截断而无法使用。
- 清除截图文字、标题、错误信息中的终端控制序列；生成的命令正确引用
  空格和引号，并保留查询、筛选、排序与资料库选择。
- 本轮不引入默认分页器、全屏 TUI、上次搜索编号缓存或新的持久状态。

## 实施顺序

1. 建立独立输出层与终端能力配置，让业务执行继续返回结构化结果。
2. 完成搜索/列表/详情、分页和摘要，并处理人类/JSON 默认值的区别。
3. 完成其他命令、进度、错误及中英文主题帮助。
4. 回归与独立验收通过后，构建 0.5.1，更新 Mac 用户目录中的 CLI。
   保留上一安装版本用于回退，继续复用现有桌面组件和模型。

## 验收

- 原有 CLI 回归及 Windows/macOS/Linux CI 通过。
- 检查 JSON 信封、字段、退出码和默认 100 条；人类默认 10 条只影响浏览命令，
  不改变导出/索引的范围。
- 用独立合成资料库覆盖长 OCR、靠后命中、中文与 emoji、空结果、分页、
  带空格/引号的查询和路径、完整 ID、终端控制字符。
- 在不同宽度、TTY/管道、颜色开关和 ASCII 模式下检查输出。
- 用真实 Mac CLI 检查原生库返回字段及桌面连接；不在用户资料库执行测试写入。
- 实际查看终端中的帮助、搜索、详情和错误，确认排版后再安装。

实现与验收中如调整范围，应将最终决定与限制记录到验收报告。
