# Recall 0.4.21：图片质量 0.5 与 720 像素视频

## 参数

- 图片：HEIC 压缩质量统一为 **0.5**，共享图块与整图回退使用相同设置。先保存无损原图并完成原分辨率 OCR，再压缩回看图片，保留文字与坐标。透明图块、HEIC 不可用或 PNG 更小时仍保留 PNG。
- 视频：最长边 **720 像素**，目标 **100 kbps**，保持 **1 fps**。3024×1964 显示器对应 720×466 回放视频。实时编码和旧视频优化引用同一份参数；独立音轨不变。
- 升级存储策略版本，使旧视频优化能识别新参数。新截图直接使用 0.5；已有共享图块不在升级时进行反复有损压缩，旧的完整图片由存储优化入口按新参数处理。

## 验证

- 31 项相关存储检查：25 通过、6 项可选集成检查跳过；覆盖原图 OCR、图块共享、图片方向与尺寸、导出、静止帧保持、音轨引用和旧档处理。
- 相同文字图片测试素材归档从上一版 33448 字节减少至 27232 字节（约 18.6%），原始 OCR 文本和坐标不变。结果只代表该测试素材。
- 直接编码的 10 秒静止画面为 720×466，可解码到末尾，没有内嵌音轨。
- 另用一段实际旧录像在临时目录验证优化输出：720 像素上限、时长与音轨检查通过。候选文件约小 9.6%，未达到原有 15% 收益门槛，因此保留原件；未为降低分辨率而强行替换用户历史。
- 安装后真实录制 52.67 秒：截图 3024×1964，回放视频 720×466，名义帧率约 1.018 fps（含结束保持帧），无内嵌音频；独立系统音轨正常载入。实机媒体检查通过，已恢复更新前的录制状态。
- Release 构建完成，使用原 Developer ID 签名，安装包与 `/Applications/Recall.app` 均严格校验。版本 0.4.21 / build 28。

Windows 未改动。
