# Recall 0.4 时间线与交互修复

日期：2026-09-25。仅修改 macOS；应用身份、权限配置、已有记录与模型保持兼容。

## 录制与时间线

- 应用激活时请求立即采样，不再等默认 3 秒间隔。请求采用序号，避免采样过程中收到的新请求被旧请求清除。
- 保留最近的有效屏幕缓冲区，在静止画面时定时续记。收到 blank / suspended 等不可用状态会丢弃缓冲区；切换应用后等待新画面，避免沿用另一应用的截图。
- 截图编码保存与 OCR 分离：画面保存成功即可进入时间线，不会因 OCR 忙而整帧丢弃。记录应用名称和窗口标题时不等待识别。
- 已保存而未完成 OCR 的帧有持久化状态，下次启动继续识别；不会将回收站中的记录重新索引或复活。异步识别保留用户已修改的收藏、删除状态。
- 连续采集带有连续段标识，空闲 / OCR 延迟不会被误画为停录。排除应用、屏幕不可用以及新录制片段保留明确的中断边界。
- 当时不再隐藏宽度小于 30 点的短应用段图标，改用错层排列。后续实机反馈显示这种排列仍有缺陷，0.4.1 改为同轨道组合入口。时间标签按当前拖动位置刷新。

## 桌面交互

- 全窗口以低透明度原生点击接收层承接透明像素区域的事件，底部 220 点区域由 AppKit 视图处理点击、拖动、滚动及捏合。
- 底部单击被消费，不会触发背后的 Dock，也不会关闭时间线；点击控件与历史卡片外的空白区域会关闭悬浮层并清理回看状态。
- 历史画面缩放为独立圆角卡片，预留顶部搜索 / 操作栏与底部时间线空间。显示 Recorded 时间标记，保留原生 Live Text，不再用等尺寸截图覆盖整个桌面。
- 自定义按钮点击区域至少 44×44 点，主要圆形按钮 50×50 点；设置使用更大的系统控件。截图内的系统图标仅属于历史像素，不会操作实际 Dock。
