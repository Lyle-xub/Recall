# Recall · 原生屏幕记忆

参考 [Rewind Demo](https://www.youtube.com/watch?v=dIV0ZiZluQo&t=11s) 的操作顺序和可见界面实现，包含两个独立的原生桌面工程：

| | macOS | Windows |
|---|---|---|
| 界面 | SwiftUI + AppKit | C# + WinUI 3 / Windows App SDK |
| 屏幕与音频 | ScreenCaptureKit、AVFoundation | Windows 原生录制 / Media Foundation，ScreenRecorderLib 封装 |
| 离线 OCR | 内置 PP-OCRv6 Small；Apple Vision / Tesseract 中英文备用引擎 | 同一 PP-OCRv6 Small 模型；独立进程，Tesseract LSTM 备用 |
| 数据 | 系统 SQLite | Microsoft.Data.Sqlite |
| 密钥 | macOS Keychain | Windows DPAPI |
| 全局快捷键 | 默认 ⌘ ⇧ Space / ⌃ ⌥ Space，可自定义 | 默认 Ctrl + Shift + Space / Ctrl + Alt + Space，可自定义 |

没有 Electron、浏览器壳、WebView 或共享网页界面。

## 运行

本次构建的文件位于：

- `release/Recall.app`：Apple Silicon，macOS 15 或更新版本。
- `release/Recall-macOS.dmg`：珍珠白背景，拖到 Applications 安装。
- `release/Recall-macOS.zip`：Mac 应用压缩包。
- Windows 新入口：`Windows/Recall.WinUI`，面向 Windows 11 22H2+、x64。当前完成源码迁移和交叉源码编译，尚未生成经过真机验证的新版安装包；验证状态见 [Windows 迁移记录](docs/windows-0.4.25-validation.md)。
- 现存 `release/RewindReplica-Windows-x64.zip` 是旧 WPF 版本，不包含本轮 WinUI 迁移。

Windows 录制和 OCR 原生库需要 Microsoft Visual C++ x64 运行库。缺少时安装 [Microsoft 官方运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。不要单独复制 exe，旁边的原生 DLL、运行时和模型文件都需要保留。

macOS 当前为 0.4.26，名称为 **Recall**，采用珍珠白圆角底座、虹彩分块玻璃背景与倾斜椭圆光环；背景纹理放大 35%、整体淡化 15%，光环右下清晰、左上柔化。应用图标、菜单栏与引导页统一使用新标识。macOS 26+ 使用分层 Liquid Glass 图标，较早系统保留完整尺寸的兼容图标。安装位置统一为 `/Applications/Recall.app`。应用标识、历史数据库、模型目录和 Keychain 标识保持兼容；升级不会丢失已有记录或下载模型。Windows 新工程也采用 Recall 名称和相同图标、光环、纹理与开场音效。

本次主分支包含 **Rhine Lab Mode（莱茵生命模式）**、全屏 Space 唤醒与 Dock 隐藏修复、统一原分辨率视频与卡片存储，以及存储设置的异步统计、优化和清理。原经典版本保留在 `legacy/main-before-rhine`（`5391af1`）；发布前快照为 `backup/main-before-release-20260926`（`ea5385f`）。

macOS 首次打开先播放约 7.2 秒全屏开场：虹彩玻璃展开、光环亮起、品牌名称出现、光影转白并过渡到五步引导。附无敲击声的原创空灵立体声音效、静音与跳过按钮；每段动画完成后才推进，最终图标停留后再淡入引导页；减少动态效果时改为短暂静态展示且不播放音效。播放状态独立保存，中断或下次启动不重复；已有记录的用户升级不自动弹出。菜单 **Welcome to Recall…** 可重播动画与引导。五步引导包含欢迎、交互时间线、权限、本地模型、开始使用。仅在明确选择 **Start recording** 后退出引导并开始记录；跳过不会自动开始录制。进入主界面后显示桌面上的悬浮搜索框和底部时间线。菜单栏显示单色光环，真实录制时附小红点，暂停时去掉红点；点击可打开 Recall、控制录制或进入设置。Demo 入口与合成数据生成器已从 Mac 应用移除，历史演示记录不会进入搜索或时间线。通过右上角 **Settings → Models** 在应用内下载默认模型。Windows 引导页与开场使用同一套素材和分段节奏，最终效果尚待 Windows 真机对照。

打开 Recall 的时间线、搜索、图片详情、Ask、设置或使用时间页面时，屏幕、麦克风和系统音频录制统一自动暂停；关闭整个界面后恢复此前的录制意愿。手动暂停不会被自动恢复。界面中选择 **Start recording** 只准备录制，关闭后才启动；需要时 macOS 会要求系统屏幕录制授权。麦克风和系统音频默认关闭，在设置中分别开启。应用窗口关闭后继续驻留菜单栏 / 系统托盘；从菜单暂停录制或退出。

## 使用逻辑

1. macOS 用全局快捷键呼出透明桌面悬浮层：桌面保持原样，中央显示液态玻璃搜索框，只有底部时间线逐渐模糊桌面。窗口高于 Dock，底部不避让 Dock，也不进入独立全屏空间。macOS 26+ 使用系统原生 Liquid Glass，macOS 15–25 使用原生材质回退。
2. 拖动或滚动底部彩色轨道，中央白色指针固定，轨道按应用的真实时间长度移动；左侧 −／＋、时间跨度菜单（1 分钟至 24 小时）、捏合或 Option + 滚动均可缩放。应用使用时段单独存储，不依赖截图或 OCR；各应用使用稳定配色，未记录的时段以中性轨道连接。密集应用入口展开为仅含应用图标与起止时间的紧凑玻璃面板；右键图标可聚焦缩放。应用条形使用细圆头胶囊与窄间距。拖动后显示缩小的圆角历史截图卡片与 Recorded 时间标记。打开 Recall 时系统隐藏 Dock，关闭界面后恢复，点击控件及卡片外的空白区域退出。左右方向键逐帧回看，点击时间标签可跳转日期，右侧箭头回到实时桌面。
3. 输入曾看到或听到的词句，显示三列历史画面卡片；顶部按应用、收藏筛选。
4. 打开卡片进入历史画面。macOS 使用原始截图的 OCR 坐标提供透明文字选择层，支持在图像上按词、跨行拖选文字，按 ⌘C 复制；顶部可复制完整 OCR 文本。历史画面上方的详情按钮打开录制、会议和转写面板。
5. 有会议窗口副画面时，左下角画中画切换会议和桌面。同一段录制的转写在右侧显示，可搜索、点击定位。
6. 右上角菜单打开 **Ask Recall**，选择本地或在线模型询问已索引的记录。回答附带可点击的来源卡片。
7. 点击搜索栏右侧的柱状图按钮打开 **App usage**，查看每日使用时间、周趋势、小时分布和应用排行；日期胶囊打开月历，也可快速选择今天或昨天。

打开界面只暂停新采集，已保存图片与音频继续在后台识别；自动存储优化在当前处理单元安全完成后等待关闭界面，设置中仍可手动选择继续。回看预览使用独立解码队列，文字选择按需布局，不会批量创建数百个文字控件。

还有图片导入、记录导出、收藏、可恢复的回收站、清空回收站、保留期限、应用排除、屏幕选择、录制视频回放和转写重试。悬浮层进出、搜索框位移、详情切换和悬停使用原生动画，并响应系统减少动态效果设置。

## 模型配置

默认 **Built-in** 模式：软件包含原生 llama.cpp / whisper.cpp 推理引擎，在 **Settings → Models** 中下载权重。首次下载需要联网，之后离线使用，无需安装 Ollama、Python 或启动外部服务。

- **Qwen3 · 1.7B Q8**：约 1.83 GB，中英文问答与总结。
- **Whisper · Base**：约 148 MB，多语言离线转写。
- 显示下载进度，支持暂停、恢复、失败重试和移除；下载完成后校验固定 SHA-256。首次提问自动启动本地引擎，退出软件关闭引擎。聊天支持流式输出和取消。
- 已有模型及在线模型仍可选，配置如下。本项目不提供在线额度。

| 用途 | Provider | API base URL | Model |
|---|---|---|---|
| 本地问答 | Ollama | `http://127.0.0.1:11434/v1` | 本机已经下载的模型名称 |
| 本地问答 | LM Studio | `http://127.0.0.1:1234/v1` | 本地服务所列出的模型 ID |
| 在线问答 | Online compatible | 服务商提供的 HTTPS `/v1` 地址 | 服务商支持的模型 ID |
| 本地转写 | Local Whisper | `http://127.0.0.1:8080/v1` | `whisper-1` |
| 在线转写 | Online compatible | 支持 `/audio/transcriptions` 的 HTTPS `/v1` 地址 | 服务商语音模型 ID |

问答使用兼容 `POST /chat/completions` 的接口，模型检测使用 `GET /models`。在线问答仅在提交问题时发送检索到的文字与相关转写，不上传截图。开启在线转写后会发送录制音频分段。本地模式仅允许回环地址，客户端拒绝自动 HTTP 重定向。

模型的下载、来源与高级接入说明见 [本地模型说明](docs/local-models.md)。仓库附带的 Python 语音服务仅为高级可选方案；默认内置模型不依赖它。

## 从源码构建

macOS，安装 Xcode 26+（含 Liquid Glass SDK）、CMake 和 Python 3.12+：

```bash
python3 scripts/prepare-ocr-runtime.py
swift test --package-path macOS
bash scripts/build-macos.sh
```

Mac 发布构建必须使用稳定的 Apple Development 或 Developer ID 证书。构建脚本优先使用现有 Developer ID，也可设置 `RECALL_CODESIGN_IDENTITY`；没有证书时直接失败，避免再次生成每次构建改变屏幕授权身份的临时签名。CI 仅编译检查时可显式设置 `RECALL_ALLOW_ADHOC=1`。

Windows，安装 .NET 10 SDK 和 Python 3.12+，在 PowerShell 中运行：

```powershell
dotnet run --project Windows/Rewind.Tests/Rewind.Tests.csproj
./scripts/build-windows.ps1
```

Windows 构建脚本使用与 Mac 相同、经 SHA-256 校验的 PP-OCRv6 与 tessdata_best 模型；OCR 运行时无需联网。新 WinUI 应用不包含 Demo 入口或数据。GitHub Actions 的双端构建流程见 `.github/workflows/native.yml`；当前工程没有推送到远程仓库或触发远程 CI。
