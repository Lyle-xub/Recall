# Recall 0.4.23 · Prism

## 视觉与流程

- 根据参考图重新绘制白色圆角底座、青粉光谱玻璃和前景镜头；镜头里的回溯弧线维持 Recall 身份。源图由 AppKit 过程绘图生成，没有复制参考位图。
- macOS 26+ 从 `Recall.icon` 编译分层 `Assets.car`，镜头置于光谱层前面，深色背景变体由系统处理。完整 16–1024 像素 ICNS 供较早版本回退，菜单栏保留单色模板。
- 五步原生引导：欢迎、可拖动/辅助功能可调节的时间线、真实权限状态、真实本地模型下载、用户实际快捷键与开始录制。没有向历史库插入演示记录。
- 白色卡片使用青粉光晕、透明叠层、共享元素转场、弹簧与文字分段淡入淡出。只在出现/步骤变化/点击时运行有限动画，没有永久计时器；减少动态效果时关闭位移、缩放与弹簧。
- 新库首次显示，旧库升级不强制显示；主菜单、菜单栏菜单和 Recall 菜单均可重播。跳过只保存引导完成，不启用录音或下载。权限操作仍需用户亲自在 macOS 确认。完成设置保留所有模型、音频、保留时间与自定义快捷键。
- 本地模型下载复用现有断点续传、取消、哈希校验和进度状态；在线/已有本地模型入口进入真实 Models 设置。
- DMG 使用 720×440 逻辑点的简洁背景，带 1×/2× TIFF；只放 Recall 和 Applications 链接，预设图标位置、隐藏工具栏。脚本通过 dmgbuild 生成 Finder 元数据，无 AppleScript。
