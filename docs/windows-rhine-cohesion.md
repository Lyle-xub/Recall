# Windows 卡片收回与玻璃菜单

本次更新延续 `feat/windows-visual-parity`，使用独立合成资料库在 Windows 原生程序中验收；不录制桌面，不读取用户历史。

## 改动

- 卡片图像、底栏和操作按钮共享投影几何。收回时连续交接底栏，避免按钮突然消失造成上下分离；标题独立等比缩放，避免压扁或双重标题。
- 右上角增加同系列圆形玻璃菜单按钮。菜单及子菜单使用独立的实时模糊背景与玻璃边缘，每个弹层分别管理材质连接。
- 搜索框旁的应用筛选显示应用名。常见进程名映射为 Microsoft Edge、File Explorer、Notepad 等友好名称；数据库筛选仍使用原始名称。合成测试资料不再使用 Research、Design 等分类名冒充应用名。
- 时间线缩放改为左侧缩小、中央时间范围、右侧放大。中央文字即时反映实际跨度，并可点击选择预设；范围为 1 分钟至 24 小时。
- App usage 与设置页一样由一张独立主卡承载，内部滚动，顶部搜索工具栏收起。总量、周/小时趋势及应用列表通过分区与细分隔组织；应用用量颜色在深浅主题分别调整，并附时长、占比和长度条。
- 退出、返回和菜单关闭路径继续统一清理弹层与背景，防止留下全屏模糊层。

## 验收边界

核心测试为 120 项。验收覆盖浅色/深色菜单、父子菜单、应用筛选、原生 Esc/返回、缩放按钮和预设，另有时间范围、动画反向、减少动态效果、隐藏/重开脚本。

收回动画三轮完成时间为 650.1、626.2、625.7 ms；对应最大 UI 更新间隔为 73.0、64.8、64.4 ms。实际缩放点击验证了 30 分钟 → 1 小时 → 30 分钟，预设验证了 15 分钟；范围脚本覆盖 21 个场景。回退/隐藏脚本覆盖 20 个路径，隐藏/重开脚本覆盖 17 个场景，另有 9 个弹层生命周期与主题切换场景。

App usage 主卡使用固定主题底色保证可读性；四种强调色相对主卡底色的计算对比度在浅色主题为 4.79–5.76:1，在深色主题为 7.64–9.18:1。颜色始终配合应用名、时长和百分比使用；对比度计算不代表所有动态玻璃背景的可访问性认证。

随附 HTML 报告含修复前后原生截图序列与诊断记录。截图序列用于观察连续性，包含截图开销；UI 更新间隔不等于 GPU 帧率。Mac 参考为静态截图，未据此宣称达到可量化的 90% 动画或材质一致性。

## 使用

完整解压 `Recall-Windows-x64-rhine-cohesion.zip` 到新目录，退出旧版 Recall 后运行 `Recall/Recall.exe`。不要只复制 exe；同目录的运行库、材质和 OCR 文件均需要保留。此包为未签名的开发构建。
