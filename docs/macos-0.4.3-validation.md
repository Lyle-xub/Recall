# Recall 0.4.3 紧凑时间线与流畅度

日期：2026-09-25，仅修改 macOS。

## 界面

- 展开面板从 352 点宽缩到 216 点宽，最大高度 230 点。只显示 23 点应用图标与精确到秒的起止时间。
- 去除 App activity 标题、应用名称、时长列与底部大按钮。保留 44 点整行点击区域、滚动和悬停反馈，应用名称可通过 tooltip 与辅助功能读取。
- 聚焦缩放放到时间线图标的右键菜单。
- 参考用户图片，应用条形改为 7 点高的独立圆头胶囊，段间视觉间距 3 点；短时应用至少保留 1 点，不更改数据库中的真实时段边界。时间指针仍固定居中。

## 性能

- 截图保存时增量插入轻量导航记录；OCR 完成只更新相关画面或搜索结果，不再每次重载 2000 张含 OCR 的完整记录。
- 时间线导航只读 id、时间、应用和连续性元数据，选择画面后异步读取该帧完整内容。查找使用二分查找，避免每次鼠标移动分配过滤后的数组。
- 搜索、时段、导航和预览采用后台 WAL 读取连接。每类请求最多一个执行中、一个最新待处理；过时结果不回写界面。
- 预览及搜索缩略图在后台串行解码，像素缓存限制为 128 MB；完整帧内容缓存保留最近 24 帧。Live Text 在画面稳定后分析。
- 主视图不再同步读图片文件获取尺寸。相同画面重复回看复用解码结果，快速换帧不闪空白。
- 时间线窗口仅随显示模式、窗口尺寸变化更新，不再响应每次游标变化重复 setFrame；固定模糊层和鼠标追踪区域不再重复布局、创建。

## 测试与测量

- 43 项测试：42 项通过，1 项显式启用的真实模型测试跳过。
- 新增验证：快速请求合并、旧结果失效、退出后不重新出现历史画面、后台采集不重置游标、只读 WAL 可见新索引、图像缓存、胶囊窄间距和短时应用可见性。
- 08:40 测量：同一组 200 条 OCR 较重的测试记录，完整内容读取 46.34 ms，轻量元数据读取 5.59 ms。
- 同次测试：1000 次缓存内拖动输入的数据处理合计 6.98 ms。这是无界面的模型基准，不代表屏幕帧率。
- 快速提交 101 个请求时，后台至多执行 2 次，只应用最终请求的结果。
