# Recall 0.4.13：共享截图与本地神经网络 OCR

2026-09-25，macOS build 19。Windows 构建未改动。

## 图片与索引

- 新截图仍先保存原始尺寸的无损 PNG，PP-OCRv6 在原图上识别；正文、矩形坐标、时间和来源写入索引后，截图才归档。没有缩小 OCR 输入，也没有从低清视频提取文字。
- 归档把图片划分为 384 × 384 像素区域，保留原尺寸；相同像素区域复用相同编码文件。每个时间点都有独立的帧记录；不做感知去重，不合并不同时间点。
- 图块使用 PNG 或 HEIC 0.80 中较小且有收益的编码。透明区域保留 PNG。HEIC 有损，因此回看中的文字选择直接使用原图生成的文字与坐标，不依赖压缩图片再次 OCR；普通 PNG 导出会重建完整截图。
- Storage → Smart storage → **Optimize images & videos** 也升级了旧截图转换。已有正文、识别矩形和 FTS 不变；已使用新格式的图片跳过。单图转换没有收益时保留原编码或较小的完整图像，并可共享完全相同的文件。
- 共享图块有数据库引用。先同步文件，再发布帧引用，最后删除无人使用的旧文件；回收站、会议画面、永久清理、导出、路径别名及中断恢复均支持共享文件。旧 UI 缓存中的多代路径会解析到当前图像，避免收藏/恢复操作写回失效地址。
- 空间不足时保留无损源图，仍可提交 OCR；后台任务取消、模型失败或转换无收益均不会覆盖原文件。

## OCR

- 内置 PP-OCRv6 Small 检测与识别模型，ONNX Runtime 1.30.0 原生 CPU 推理；没有 Python 运行时依赖。检测最长边 1280，识别读取原图裁剪，支持中文、英文及模型支持的其他文字。
- 原生工作进程常驻，缓存完全相同的文字区域；缓存不使用模糊相似度。IPC 有大小限制、45 秒截止时间、取消与失败重启，失败可退回现有 Vision/Tesseract 引擎。截图、识别结果和缓存都留在本机。
- 模型固定 URL 与 SHA-256，构建脚本为 `scripts/prepare-neural-ocr.py`；ONNX Runtime、OpenCV、Carotene 与模型许可证随应用分发。
- [PaddleOCR 官方 PP-OCRv6 文档](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/algorithm/PP-OCRv6/PP-OCRv6.en.md)；模型转换与预后处理参考 [RapidOCR](https://github.com/RapidAI/RapidOCR)。下列数字来自本机测试，不是厂商的通用准确率承诺。

## 视频

- 回放改为 HEVC、最长边 960 像素、1 fps、目标视频码率 150 kbps，音轨原样保留。原始屏幕流降至 3 fps，以减少五分钟录制段归档前的临时文件；3 秒截图间隔和原始像素尺寸保留。
- 仅替换已经结束的录制段；验证音轨数、时长、分辨率、帧率和实际解码。至少节省 15% 才接受，未通过时保留原视频。
- 视频只是低帧率回放，快速运动会明显不如前版连贯。OCR 与全文搜索不使用视频。
