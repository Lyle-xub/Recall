# Recall 0.4.5 设置布局、快捷键与存储

日期：2026-09-25。仅 macOS。

## 功能

- 设置改为 660 点宽、按屏幕高度适配的纵向单列窗口：顶部标题与分类切换、内容独立滚动、底部固定保存按钮。
- Open / hide、备用键、搜索、前后时刻、返回、设置快捷键均支持点击录入。录入期间暂停全局键，Esc 取消；支持禁用备用键和恢复默认。
- 保存前检查不支持的按键、标准 macOS 命令和重复绑定。系统拒绝新全局组合时，撤销新注册，保留旧注册与磁盘配置。
- 快捷键与 Dock 图标选项持久保存；旧版 settings.json 缺少新字段时补默认值，不重置其他偏好。
- Dock 图标开关通过 NSApplication activation policy 生效，可在 Dock 和应用切换器中显示。菜单栏保持可用。时间线打开时隐藏整个 Dock 的既有逻辑保持。
- 存储页显示真实 size-on-disk：截图、视频、音频、下载模型、SQLite 索引及其他文件。环形图显示组成，另有磁盘可用空间与占用条。
- 文件统计后台执行，可取消、手动刷新；包括回收站内尚未删除的文件，忽略符号链接，不跟随链接重复计数。支持独立模型目录。
- 仅改变快捷键或 Dock 图标时不重启录制；采集选项改变才重启采集。
