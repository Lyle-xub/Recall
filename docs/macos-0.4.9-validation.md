# Recall 0.4.9 界面与存储清理

2026-09-25，macOS，构建 15。已安装至 `/Applications/Recall.app`。

## 界面

- 搜索结果、应用筛选、Ask 对话及来源、设置、排除应用编辑器、应用使用时间、时间线分组、文字预览和转写使用 `scrollIndicators(.never)`。实机发现 `.hidden` 和 `showsIndicators:false` 仍可能遵循系统滚动条偏好而显示滚动条，最终改为 `.never`；触控板和鼠标滚动保留，不修改系统偏好。
- 主搜索栏移除内部 ⌘F 提示；右侧依次为应用筛选、收藏、Ask Recall、App usage、设置。新增使用时间按钮沿用现有液态玻璃和依次弹出的弹簧动效，宽度重新分配。
- 使用时间日期入口改为圆角胶囊与弹出月历：月份切换、当天标识、选中日期、今天/昨天快捷选择，禁止未来日期；周起始日与本机日历保持一致。
- 转写搜索缩为最大 242 点宽、44 点高、22 点圆角的玻璃胶囊。右侧图标统一灰色，命中结果为空时禁用；回车和向下按钮循环定位匹配行，滚动动画遵循系统减少动态效果偏好。

## 存储清理

- Storage 新增 **Clear storage…**，可选择回收站、30 天前、7 天前或全部录制记录，默认保留收藏。先展示记录数量、完整录制段数量、预计可释放媒体空间，永久删除前再次确认。
- 跳过正在录制及未正常结束的录制段；共有截图或仍被保留记录使用的音视频、转写不会删除。下载模型、应用配置和应用使用时间历史保留。
- 范围预览后台只读加载。确认只授权预览中的记录集合；真正执行时在数据库写锁下重新核对收藏、录制状态与共享路径，不删除预览之后的新记录。
- 媒体先移入本地临时清理目录，写入恢复日志，再提交数据库事务。提交前中断会恢复媒体，提交后中断会在下次启动完成媒体移除；拒绝越界路径及媒体符号链接。
- 后台转写完成后检查原录制段仍存在。OCR 的存在检查与更新共用写锁，防止清理与异步索引并发时复活记录；已移除的待索引截图不会弹出多余错误。
- 预计空间指媒体文件实际分配大小，不承诺等量缩小 SQLite 文件；已删除索引占用的数据库页可由后续记录复用。

- 81 项测试：78 项通过，3 项可选集成测试未启用，无失败。新增 7 项清理检查覆盖年龄范围、收藏、未结束录制段、共享媒体、预览快照边界、路径验证、提交前后中断恢复、延迟转写和 OCR。删除仅发生在临时测试库。
- Release 构建成功。固定 Developer ID 签名、音频输入 entitlement、深度严格签名校验通过；安装版与发行版二进制一致。
- 实机从搜索栏 App usage 按钮进入统计页，验证前月导航、昨天空数据和回到今天；设置页、使用时间页滚动正常且无可见滚动条。录制设置的多行编辑器也不再出现滚动条。
- 实机 Storage 预览：默认回收站为空时禁用清理；全部范围能返回真实数量与空间估算。随后取消，未执行用户记录清理，也未修改其偏好。
- 在真实转写详情页确认搜索框尺寸、圆角与无滚动条显示。用户开始操作转写输入框后停止自动点击，因此未把按钮逐项交互列为已完成的实机检查。
- 录制已恢复，最终只读抽查新会话 48 张截图、48 张索引完成；未再次请求屏幕或麦克风授权。
