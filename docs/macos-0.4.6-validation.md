# Recall 0.4.6：权限、录音修复与动效

2026-09-25，仅 macOS。最终安装构建为 11。

## 麦克风修复

- 原发布应用开启 Hardened Runtime，却缺少 `com.apple.security.device.audio-input`。新增 `macOS/Recall.entitlements`，签名脚本为主程序和应用写入音频输入声明，继续使用同一 Developer ID。没有重置系统授权或更换应用标识。[Apple 音频输入权限说明](https://developer.apple.com/documentation/BundleResources/Entitlements/com.apple.security.device.audio-input)。
- 将权限单独放入设置：屏幕及系统音频、麦克风分别显示状态，支持请求、进入对应系统设置和刷新。应用重新激活时同步状态。
- 麦克风授权在更改采集配置、停止已有录制之前检查；未启用麦克风时不发起请求。
- 初次实机授权后发现第二个问题：09:44 和 09:45 的崩溃报告定位于 `AudioTrackSink` 创建 `AVAssetWriterInput`。系统日志明确指出 96000 Hz 不是本机 AAC 编码器接受的采样率。
- 现在输出明确使用 48000 Hz、单声道或双声道 AAC，并传入真实源格式，由 AVAssetWriter 转换输入 PCM。构造输入前先用 `canApply` 验证输出设置，避免 Swift 无法捕获的 Objective-C 参数异常。[Apple 源格式提示接口](https://developer.apple.com/documentation/avfoundation/avassetwriterinput/init%28mediatype%3Aoutputsettings%3Asourceformathint%3A%29)。

## 界面与动效

- 设置使用单层白色表面，原生 sheet 负责外缘圆角，移除重复玻璃外壳和 Recall 品牌标题。
- 纵向内容滚动、固定保存区域保留；五个分类包括独立权限页。卡片使用细浅色边线，存储环形图变为低饱和蓝、淡紫、薄荷等配色，环宽减小。零占用显示为 `0 KB`。
- 时间线进场淡入并上浮 20 点，退场淡出并下沉；Dock 在整个退场完成后恢复。
- 用代次检查防止旧动画的完成回调关闭刚重开的窗口。减少动态效果开启时取消位移与延时动画。
- 搜索框点击后收缩为胶囊，展开应用筛选、收藏、AI 问答和设置四个圆形按钮；显式搜索快捷键和开始输入同样触发展开。
- 原生文本编辑器会吞掉 SwiftUI 点击手势，因此只在搜索框内观察本进程的 mouseDown，并原样返回事件；不重建、不截断、不转发鼠标事件。
