# Recall 0.4.4 交互稳定性与设置页

日期：2026-09-25。仅修改 macOS，保留应用身份、数据库、下载模型、Keychain 和现有权限。

## 排查结果与修改

- 用户报告点击后闪退。检查时旧版进程仍然运行，没有找到 0.4.3 的崩溃报告；仅发现历史 0.3.0 崩溃报告。本轮实测也见到窗口消失而进程保留。
- 移除 `applicationDidResignActive` 自动关闭。焦点切换到时间线子窗口、菜单或设置面板不再被当作关闭请求；关闭由空白点击、关闭按钮、Esc、快捷键或系统显式隐藏触发。
- 主窗口与时间线使用可激活的原生 NSPanel，先激活应用再显示窗口，避免一面要求应用激活、一面用 nonactivatingPanel 抑制激活。
- 整屏原生 DesktopClickShield 改为 SwiftUI 背景手势，使空白点击与按钮处于同一个命中测试树。背景保留微小非零 alpha，阻止透明区域把点击传到背后应用。
- 全局快捷键注册到 Carbon 事件分发器，检查事件签名与 ID，监听按下和松开，长按只触发一次。显示状态使用逻辑状态，避免关闭动画期间 `isVisible` 仍为 true 的歧义。
- 保留 ⌘⇧Space，增加 ⌃⌥Space。设置中显示实际注册状态，可重试注册；不增加辅助功能或输入监听权限。日志只记录注册状态与快捷键编号，不记录键入内容。

## 设置页

- 左侧固定分类：Recording、Models、Storage、Shortcuts。右侧采用圆角玻璃卡片、统一留白、独立滚动区域和固定底部操作栏。
- 录制状态与启动按钮放到首张卡片，屏幕、音频和应用排除分组排列。
- 内置模型保留下载安装状态；其他模型服务显示标签清楚的 URL、模型、密钥输入区。
- 存储保留期限、导出、回收站功能保留；回收站入口修正为确实打开搜索结果视图。
- 快捷键用按键样式展示，同时显示注册成功或冲突原因。
