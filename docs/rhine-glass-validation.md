# Recall 玻璃档案界面

分支：`feat/rhine-glass-replica`。基线：`5391af1`（原项目首次快照）。本次修改针对 macOS 原生界面。

## 画面与交互

根据用户提供的参考图迭代相机、卡片倾角、前排高度、玻璃厚度、反光和景深。最终使用 SceneKit 的真实三维卡片，SwiftUI 保留品牌、工具栏、搜索和记录操作。截图内容与品牌保留 Recall，不使用参考图中的音乐封面或水印。

- 设置 → Recording → Appearance →「玻璃档案首页」为持久化可选项，默认关闭；保存后生效。关闭时恢复透明桌面、中央搜索框与底部时间线，不挂载 SceneKit 渲染器。
- 首页展示连续五个自然日，从左至右日期递增，每列只放当天的真实截图。默认以最近录制日为中心；底部前一天／后一天切换日期窗口。每列预览最近 48 张不同截图，完整记录仍可通过记忆库与时间线访问。
- 缺失日期、较短列的缺位，以及各列前后两个位置由空玻璃片补齐。空片没有 record ID、截图、OCR 或点击操作，不生成 Demo 记录。日历运算按本地时区进行，覆盖跨午夜及夏令时边界。
- 滚轮与触控板纵向移动阵列；横向滑动或按住拖动浏览两侧，支持系统的触控板惯性事件和边界限制。
- 中央尖峰与两侧宽缓山肩构成连续高度场；鼠标位置和滚动推动波峰，各排通过保留速度的阻尼弹簧依次起伏，停止输入后自然收稳。
- 点击记录先滑出队列，再转向镜头；收起、点击空白或 Esc 沿同一路径归位。中途反向操作保留当前位置和速度，不跳回起点。
- 截图、信息和操作按钮始终附着在同一个 SceneKit 卡片节点。取出／收回不更换封面、不使用淡入淡出，也不另建详情卡片；收藏或加载图片保留移动节点。
- 展开时同一张卡片连续改变宽高，按原截图比例放大到窗口内；移除截图中的固定竖向底色和蒙层，大图下方仅保留紧凑的信息与操作栏。自动读取较高分辨率预览，收回时连续恢复玻璃阵列形状。
- 展开完成后，透明的原生 OCR 选择层对齐三维图片的投影边界。可以拖选、跨行选择并用 ⌘C 或右键复制；收起开始即撤掉交互层，图片本体始终留在原卡片上。没有索引区域时异步识别当前截图。收藏、复制全部识别文字、回到此刻仍接入原操作。
- 展开卡片的收藏、复制文字、回到此刻、收起统一为四等分按钮，共用绘制与点击区域；文字基线、高度和间距一致。返回按钮与当前右侧工具栏使用同一垂直中心。
- 降低玻璃色素和金属感，增加透明层叠；限制过亮的高光，保留细边反射、冷暖光与连续景深。
- 保持搜索返回后的阵列状态；响应系统减少动态效果设置；无障碍卡片名称附真实记录时间。
