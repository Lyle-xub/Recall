# Recall 0.4.11 存储优化与识别恢复

2026-09-25，macOS，构建 17。Windows 不改动。

## 截图与识别

- 截图继续采用原始屏幕像素，先原子保存无损 PNG，识别原图后再选择 HEIC 0.92 / PNG 归档。文字、位置和来源链接在压缩前保存；归档失败时保留原图和已完成的文字。
- HEIC 必须可解码、尺寸一致且比 PNG 小约 17% 以上，否则保留 PNG。内容哈希共享完全相同的图片，OCR 缓存最多六张；不以感知相似度跳过内容，不减少时间线时间点。
- 索引、共享媒体清理、导出和会议副画面都核对引用。数据库更新成功后才删除无人引用的旧源图；重启可恢复待识别原图。
- 现有三张真实 3024 × 1964 截图，与旧 JPEG 0.9 编码比较：总计 2,787,663 → 1,772,729 字节，减少 36.4%。中英文合成图为 82,159 → 38,984 字节，减少约 53%，原图 OCR 文本保持一致。这些是样本比较，不是整库节省承诺。
- HEIC 为有损归档。搜索使用已保存的原图 OCR；macOS Live Text 再次分析归档图像时可能有不同结果。

## Screen indexing 故障

- 复现了系统 TextRecognition.CRImageReaderError error 1，系统日志对应 E5RT precompiled compute operation code 13。单纯切换 Vision 计算设备仍存在间歇失败。
- 正常优先使用 Apple Vision accurate。系统引擎报错或超过八秒未返回时，取消该请求，改用内置 Tesseract 5.5.3 LSTM 与 tessdata_best 英文、简体中文模型。备用引擎完全本地运行，与 Vision / Neural Engine 无关。
- Tesseract、Leptonica、libpng 从固定版本、SHA-256 校验后的源代码静态编译，目标 macOS 15.0；只动态链接系统 libc++、libSystem、zlib，不依赖用户安装 Homebrew。附带依赖和模型许可证。模型权重随应用内置，无需再下载。
- 备用识别直接读取无损原图，并保留文字矩形坐标。TSV 按行合并，中英文、数字、中文词间空格和归一化坐标均有测试。单次备用请求最长三十秒，后台计算受限，临时文件仅本机可访问并在完成后清理。
- 引擎故障后缓存备用状态一小时，避免重启后再次陷入同一故障。取消操作不会触发备用识别。两套引擎都失败时保持原图和未完成标记，以 2 / 4 / 8 / 16 / 30 秒退避重试；不再每张图片弹出模态窗口。Recording 设置显示非阻塞状态，新截图优先于旧积压。
- 备用模型与 Apple Vision 的逐字结果不保证一致；没有使用降分辨率图片来换取识别速度。

## 轻量视频

- 根据用户最后确认，视频仅用于回放。视频归档中完全移除 OCR、PSNR 和文字清晰度门槛；截图识别不从视频提取画面。
- 正常结束的录制段转为 HEVC，最长边 1280 像素、最高 3 fps、目标视频码率约 450 kbps，保持原方向、会话时间与原有压缩音轨。录制过程中暂存原始流，每段结束后后台压缩。
- 校验候选视频能解码、时长、音轨数、输出尺寸和帧率，且至少节约 15% 空间。未通过结构检查或编码失败时保留原片。
- 真实三十秒样本：25,690,112 → 3,272,704 字节，减少 87.26%，处理约一秒。该数值不是所有片段的固定压缩率。
- 新片段自动排队；Storage → Smart storage 可优化已有录制及暂停。策略版本会重新检查早期被高清文字门槛拒绝的片段。
- 候选先完成写入并同步，数据库先发布新路径，再删除无人引用的旧片。会话已删、仍录制、源文件期间变化时拒绝替换。退出不等待卡住的系统调用；未发布临时文件下次启动回收。

## 安装与实机验证

- 92 项测试，89 项通过、3 项可选集成测试跳过，零失败；Release 编译通过。测试包括真实三十秒视频压缩、时长与音轨、取消、数据库提交竞争、原图引用和 OCR 超时恢复。
- 已以原 Developer ID 签名安装 `/Applications/Recall.app` 0.4.11 / 17，嵌套引擎与应用严格签名校验通过，安装二进制与发行包一致。设置 JSON 语义比较一致，未重置权限、快捷键、模型或音频设置。
- 实际打开 Storage 并启动 Optimize existing recordings，进度和空间占用随任务更新。原有 68 个会话保留；66 个已结束会话均完成策略检查。视频文件总量从 13,114,613,135 降至 1,031,365,373 字节，减少约 12.08 GB（92.1%）。两段未正常结束的历史会话未做替换。该整库数字与前述三十秒样本的压缩率不同。
- 对实际替换的 65 个视频逐一重新读取容器：全部存在、时长有效、最长边不超过 1280、帧率不超过 3 fps。另一个已检查片段保留原片。启动后的 41 次 OCR 完成记录均成功，未出现索引延迟错误或视频优化失败。
- 新版启动后，本机积压待识别截图从 183 张降至 147 张时复核通过；日志持续记录 `mode=local-lstm`，原先报错的图像已生成非空文字与矩形区域，随后归档为 HEIC。积压继续在后台处理，未声称已全部补齐。备用识别处理复杂整屏所需时间可能超过三秒采样间隔，因此搜索索引可能滞后于时间线。
- 本轮验证了真实历史视频压缩与积压截图识别；录制保持暂停，未把界面操作尝试当作新录制成功。原有屏幕采集配置仍以完整分辨率暂存，已结束片段才转为轻量视频；因此录制中的临时文件会大于最终归档。
- macOS ZIP 共 215 项、42,182,060 字节，CRC 检查通过，SHA-256 为 `7c3a0bff195f4862a594fed0e873698b3068765d3b2c9c3ed0b48d81e548477f`。Windows ZIP SHA-256 保持 `56b2576fc9d5779e85734a1498b094249a68055fc57c09045045d7cef6adde1f`。
