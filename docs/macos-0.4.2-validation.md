# Recall 0.4.2 连续时间线

日期：2026-09-25。仅修改 macOS。

## 应用使用记录

- SQLite 新增 app_usage 表，保存应用名称、bundle ID、开始时间、结束时间和状态；不保存窗口标题或 OCR。
- 使用 NSWorkspace 应用激活通知记录切换时间，同时每 5 秒检查一次前台应用并保存检查点。应用切换与截图保存、OCR 完成相互独立。
- 前一时段的结束时间与下一时段的开始时间相同。暂停、退出、流错误和睡眠停止记录；重新启动不会把两次运行之间的时间归给上次应用。
- 排除的应用只保存匿名的 Private activity，不保留名称或 bundle ID。使用时段遵循已有保留天数。
- 旧数据通过轻量的截图应用信息兼容显示；新记录使用独立时段清单。没有记录的部分显示中性轨道，整条轨道不再断开。
- 未捕获截图的应用时段仍显示在轨道上，拖到这些时段时显示 No screen captured at this time，不展示其他应用的旧截图。

## 界面

- 应用使用稳定的专属配色；ChatGPT 为青绿、Obsidian 为紫色，未预设应用按 bundle ID 获得稳定色相。
- 重叠图标展开为圆角玻璃面板，包含应用图标、起止时间、停留时长、悬停反馈和 Zoom into these apps。44 点以上的操作区域保留。
- 新增 −／＋和 1 分钟、5 分钟、15 分钟、1 小时、6 小时、24 小时跨度菜单。继续支持捏合和 Option + 滚轮缩放，缩放保留时间指针位置。
- 根据跨度调整时间刻度，视口按需加载应用时段，旧历史轨道查询不再受 2000 张截图窗口限制。
- 时间线模糊过渡区域从 220 点扩为 280 点，顶部 18% 完全透明，然后以连续且两端平缓的曲线增加遮罩透明度。去掉独立面板整块 2% 黑色底色，消除其矩形上边缘。
- Dock 隐藏和全屏 Space 原生浮层逻辑沿用 0.4.1，未重新引入鼠标事件过滤。

## 验证

- 38 项测试：37 项通过，1 项显式启用的真实模型测试跳过。
- 新测试覆盖：无截图时连续快速应用切换、重复检查点、暂停/重启边界、排除应用匿名化、跨视口长时段查询、历史数据切换、新记录缺图回看、缩放指针稳定、配色与模糊曲线连续性。
- Release 构建通过；应用沿用同一 Developer ID 签名安装到 /Applications/Recall.app。
- 实际界面验证：−／＋、跨度菜单切换至 1 小时、重叠应用列表、列表内聚焦缩放均可操作；聚焦后视口跳转到对应历史时间并展开应用图标。
- 实际录制已启用，app_usage 表产生使用时段并持续保存检查点，截图与 OCR 同步运行。已观察到 Recall → ChatGPT 的使用时段边界完全相接；完整前台多应用切换仍等待用户手动反馈。最终版本已重新启动并恢复录制。
- 原生 UI 自动化操作后台窗口不会自动改变系统前台应用；人工切换应用与桌面背景上的模糊观感反馈另行核对，不将后台 AX 操作当作前台切换验收。

安装包：release/Recall-macOS.zip。校验值：release/checksums.json。Windows 安装包不变。
